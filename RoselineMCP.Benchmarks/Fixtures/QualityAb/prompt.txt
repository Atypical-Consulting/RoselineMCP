The Core project in this solution (Fixture.sln) has OrderPricing.ComputeTotal(decimal unitPrice, int quantity). Change it so it also takes a decimal taxRate parameter (a fraction such as 0.21m) and returns the total including tax, that is unitPrice * quantity * (1 + taxRate). When you are done the whole solution must build with `dotnet build Fixture.sln`. Wherever a tax rate is needed and none is available, use 0.21m.
